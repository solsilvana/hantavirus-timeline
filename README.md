# 🦠 Brote de Hantavirus (Virus Andes) — M/V Hondius

Línea de tiempo epidemiológica interactiva desarrollada en HTML/CSS para visualizar cronológicamente el brote de hantavirus asociado al crucero internacional **M/V Hondius** durante abril y mayo de 2026.

## 🌍 Objetivo

Este proyecto busca representar de forma visual y académica:

- la evolución temporal del brote,
- el movimiento geográfico del crucero,
- las evacuaciones médicas,
- la respuesta sanitaria internacional,
- y la coordinación epidemiológica entre países.

El ejercicio fue desarrollado como herramienta de comunicación epidemiológica y análisis geoespacial aplicado.

---

# ✨ Características

- Línea de tiempo horizontal estilo infografía epidemiológica.
- Clasificación visual por tipo de evento:
  - navegación,
  - inicio de síntomas,
  - fallecimientos,
  - evacuaciones,
  - respuesta sanitaria.
- Tabla resumen de casos.
- Diseño responsive en HTML y CSS puro.
- Compatible con GitHub Pages.
- Inspirado en cronologías de brotes y visualizaciones de salud pública.
